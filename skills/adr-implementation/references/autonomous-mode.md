# 明确授权的自主模式

仅用户明确选择“自主模式”且给定目标时适用。“继续”“接管”或任务很大本身不等于授权。记录唯一主目标、完成谓词、明确排除项、当前阶段、已授权操作和暂停条件；权限不因后续技术发现自动扩大。

在目标与现有授权内，可规划必要技术 ADR 和有界修复；决策记录要标明是代理在授权内作出，不能声称用户亲自批准。新的架构或持久合同先经过 `adr-writing` 与独立方案审查。真实付费、推送、生产、删除和超出目标的配置操作仍需各自权限。

对发现的问题先取证并分类：阻断当前验收或破坏既定不变量的，建立最小修复块、验证后回到主线；附近且低风险的已证实缺陷可独立归因处理；无关、推测或大范围清理放入待办；涉及新产品目标、计费/数据政策或明确排除项的，停下受影响行为请用户决定。不要因修复跨文件就误判越权，也不要借自主模式无限扩张。

每个修复块记录与主目标的关系、受影响合同、验证和返回点。已失败的同一门禁不因新建阶段或 ADR 而重置审查次数。进度更新后继续已获授权的下一阶段，只有完成、用户停止、确实缺少重大决定/权限/输入，或不可自行解决的阻塞时结束。
