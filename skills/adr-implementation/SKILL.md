# ADR 阶段实施

本组件负责 ADR 的第二段作用：把已确定方案落实为可验证的成果。它管阶段状态、依赖和证据，不替代领域实现、测试、代码审查或发布专长。仅用户明确要求执行 ADR 才进入实施；明确仅写 ADR 的请求停在文档阶段。

本组件依赖同级 `adr-review` 的审查输入指纹规则。若无法读取该规则或相应审查材料，记录证据缺口并停止受影响的实施门禁。

## 开始条件

1. 找到治理本次行为的 ADR、唯一阶段计划、测试合同、代码身份和实际授权。新写或重大修订的 ADR 需有独立审查 `PASS`；按 [审查输入指纹规则](../adr-review/references/input-fingerprint.md) 复算并核对当前 ADR、阶段计划及测试合同，确认重大待决项已关闭、主智能体已记录可实施门禁。输入变更而无有效复审时旧 `PASS` 失效。历史已接受 ADR 不因缺少新门禁记录而自动失效。尚未决定的产品取舍回到 `adr-writing`，不能靠实施代码替用户选择。
2. 区分本地编码/测试、提交、推送、真实付费调用、数据库或生产操作的授权。执行一个 ADR 的授权覆盖其已确定的本地实施范围，不自动扩展到外部或高风险操作。自主技术规划仅在用户明确选择该模式时启用，并限于指定目标；此时先读 [自主模式边界](references/autonomous-mode.md)。
3. 核对项目规则、工作区与已有变更，保留无关工作。只取得当前阶段所需的 ADR 条款、直接代码事实和验收条件，不把全部历史记录压入工作上下文。

仅在**进入实施、首次修改源码之前**检查目标工作树的已跟踪及未跟踪改动。工作树干净时，可沿用项目活动工作树及现有依赖；存在改动时，按项目规则和用户选择决定是否隔离，确保不会覆盖或误提交现有工作。需要隔离时，选择运行环境允许且项目认可的位置，核对源码起点并保留原工作树。变更归属或实施位置无法安全判断时，说明具体冲突并向用户确认；不得把沉默视为清理或提交授权。此规则只适用于 ADR 实施，不适用于 ADR 写作、规划或方案审查。

## 单阶段循环

对第一个未完成且依赖已通过的阶段：固定可观察结果、`FR` / `TR` 覆盖、允许改动范围、非目标、接口/数据/权限不变量、错误行为、测试与验收谓词。使用项目现有的唯一状态记录；没有合适格式时按 [阶段门禁](references/phase-gates.md) 建立最小记录。实施一项内聚变更，运行相称的测试，取得独立实现审查，修复并复核，然后在指定环境验收。通过后同步阶段、ADR 映射、风险和交接证据。

在获准范围内继续下一个阶段，除非用户只指定当前阶段、明确要求停止，或确有无法自行解决的重大决策、权限、输入或阻塞。进度汇报不等于另一次批准请求。原合同下必要的有界修复可跨模块，但不得以此扩张产品目标或顺手清理无关债务。

实施与每轮代码审查均对照原始目标、范围基线及后续已授权变化，检查累计改动是否必要、是否复用既有能力、是否保持旧行为和完成条件。委派实施审查时，提供或指向范围基线、用户已授权变化、累计变更的起点与当前代码身份（含相关未提交改动）及本阶段差异，要求审查者单列范围、复用和必要性判断；发现不属于已授权目标所必需的扩项，或显著扩张缺乏必要性论证且影响交付时，要求修改。显著扩大共享模块、迁移或验证范围前，先记录触发证据、影响并比较满足同等安全和行为约束的较小可行方案；无合理替代时说明依据。已授权的必要有界修复直接推进，无关且不阻断交付的旧问题登记后续。对受影响旧功能做相称回归；复用受检版本和输入未变且仍有效的证据，代码变化或证据失效的部分重新验证。满足已确认的验收与交付条件后收口，不以假设风险或偏好持续扩大范围。

实施中若发现需要改变 ADR 的持久合同或产品决定，按 [阶段门禁的决策回退](references/phase-gates.md) 保存当前代码与阶段证据，再回到 `adr-writing` 与独立方案审查；不得静默沿用旧审查 `PASS`，也不自动丢弃、提交或回滚用户改动。

## 证据与交付边界

- 单元、集成、浏览器、真实 Provider 和生产验收是不同层次；只报告实际观察到的层次。未知外部提交状态不得伪造成功、失败或重复付费授权。
- 实施审查最多两次修复、三次结论；最终仍失败则标记阻塞并分析受影响的后续阶段。授权、输入、环境或证据缺失各用真实原因记录，不一概称作代码缺陷。
- 项目或用户要求提交时，只提交本阶段精确范围并验证结果；分支和工作树按项目规则及实际授权处理，不靠丢弃无关改动制造干净状态。推送和生产发布分别需要其自身授权与验收。
- 只有实现、测试、独立审查、验收和文档同步全部通过，阶段才可写成 `PASSED`。完整 ADR 交付还需所有授权阶段通过，遗留风险已说明，不能用“下一步会做”代替当前工作。
